[POSTS] app.py + feed.html

    👍 like ❤️ love 😮 wow 😂 haha 😢 sad 😡 angry
    Hover (desktop) / tap-and-hold (mobile) reveals picker; click again removes reaction;
    per-type count summary shown under each post. Old likes table kept but unused.

[MESSAGING] app.py + messages.html + create_group.html (NEW)
  - 1-on-1 chat verified working: send/reply/mark-read/auto-scroll/timestamps/sent-vs-received
  - NEW tables chat_groups, group_members (with last_read_at), group_messages
  - New Group page: name + multi-select alumni; group list in Messages sidebar with
    unread badges; group thread shows sender name + avatar; creator can add/remove
    members, rename, delete group; notifications on group add + new group message.

[PRESERVED] all existing tables/routes: users, graduate_master, posts, comments,
  likes, comment_likes, messages, notifications, homecoming_events, announcements,
  full admin panel, public directory, auto-verification on registration.
